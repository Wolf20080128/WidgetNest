## 两条扩展路线怎么选

```
想做的东西能用「取一条命令输出 / 读一个文件 / 显示时间」拼出来？
   ├─ 能  → 写 widget.json（自定义组件），零编译，随改随用
   └─ 不能 → 加 C# 内置组件（WidgetView），跟着版本发布
```

自定义组件**可以执行任意命令**，这一点在导入确认窗里会明确列出；内置组件则是随程序一起签入的代码，走正常的审阅流程。
